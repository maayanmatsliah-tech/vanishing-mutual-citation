# The Vanishing Mutual Citation
Replication code and data pipeline for the paper *The Vanishing Mutual Citation*, an empirical study of long-term mutual citation trends from 1975 to 2023 using the OpenAlex citation graph.
> Detailed findings, interpretations, and results are presented in *The Vanishing Mutual Citation* paper.
